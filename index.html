How a MOSFET turns on, step by step

  1. Off: with no gate voltage the body’s majority carriers (holes in an NMOS) sit right under the oxide. The source and drain are separated by two back-to-back PN junctions, so nothing flows.
  2. Depletion: a small positive gate voltage pushes the holes away. Fixed, charged dopant ions are left behind. They cannot move, so there is still no current.
  3. Inversion: above the threshold voltage Vth, the gate pulls in enough electrons to form a thin n-type layer under the oxide: the channel. It now connects source and drain.
  4. Linear (triode): a small VDS makes electrons drift through the channel. The device behaves like a resistor whose value the gate sets.
  5. Saturation: once VDS ≥ VGS − Vth, the channel pinches off at the drain end. Extra VDS mostly drops across the drain depletion region, so the current levels off.

Why the current stops growing in saturation

The gate-to-channel voltage at the drain end is VGS − VDS. When that falls to Vth, the drain end of the channel can hold no more carriers: it pinches off. Carriers that reach the pinch-off point are swept across the strong field of the drain depletion region, so the current is set by how many carriers the channel can supply, ½k(VGS − Vth)², not by VDS.

How a CMOS inverter works

  1. The PMOS connects the output to VDD, the NMOS connects it to ground. Both gates share the input.
  2. Input low: the NMOS is off and the PMOS is on, so the output is pulled up to VDD (logic 1).
  3. Input high: the PMOS is off and the NMOS is on, so the output is pulled down to 0 V (logic 0).
  4. Only one transistor is on in each steady state, so almost no current flows. Current flows only briefly while switching, when both are partly on.

The five regions of the transfer curve

The switching point VM is where Vout = VDD/2. It sits where the NMOS and PMOS are equally strong. Holes are slower than electrons, so with equal widths the PMOS loses and VM moves below VDD/2. Making the PMOS about 2.5× wider balances them and gives equal noise margins for 0 and 1.

Where the power goes

Static power is almost zero. Dynamic power is spent charging and discharging the load capacitance each time the output switches: P = α·C·VDD²·f. That is why lowering VDD (see DVFS in the Power tab) saves so much energy.

Response and threshold shift

Why the body effect appears here

Explain the terms: body effect, VSB, γ, stacks, weak 1

What the body effect is

  1. Every MOSFET has a fourth terminal, the body (substrate or well). In digital circuits it is tied to ground (NMOS) or VDD (PMOS).
  2. If the source rises above the body, the source-body junction is reverse-biased by VSB.
  3. That reverse bias widens the depletion layer under the gate, so it holds more fixed charge.
  4. The gate must now overcome that extra charge before it can form a channel, so the threshold voltage rises: Vth = Vth0 + γ(√(2φF + VSB) − √2φF).

Right now:

How designers live with it

  • In a NAND/NOR stack, put the latest-arriving (critical) input on the transistor closest to the output, so the slow-to-settle middle node is already charged.
  • Keep stacks short (2–3 transistors) and size the stacked devices wider.
  • Use a transmission gate (NMOS + PMOS) instead of a single pass transistor, so a full 0 and 1 are passed.
  • In analog circuits, put the transistor in its own well (or a deep n-well / triple-well process) and tie body to source, which removes the effect.

How the output voltage is changed (modulated)

  1. LDO: Vout = Vref·(1 + R1/R2). Change the divider ratio or the reference voltage.
  2. Buck: Vout ≈ D·Vin. The controller changes the duty cycle D: the PWM comparator keeps the high side on until the ramp crosses the error-amplifier output.
  3. PMIC: the processor writes a VSEL code over I²C/SPMI. A DAC turns the code into a new reference, and the regulator’s loop moves the output there at a controlled slew rate.

Why it matters: a processor’s dynamic power is P = α·C·V²·f. Dropping the core from 1.05 V to 0.60 V at idle cuts that power by about 3×, which is the whole point of DVFS.

Spectrum and trade-offs

How it works

Explain the terms: Rmax, beat frequency, “no peak”, PLL words

How the radar turns distance into a tone

  1. The radar sends a chirp: a signal whose frequency rises steadily, e.g. 76 → 77 GHz in 40 µs.
  2. The echo comes back a little later, so at every moment it is at a slightly lower frequency than what is being sent.
  3. Mixing the echo with the transmit signal leaves the difference: a tone called the beat frequency fb. The farther the target, the longer the delay and the higher the tone: fb = 2·R·S / c.
  4. The receiver filter and ADC only pass tones up to the IF bandwidth (20 MHz here). The distance whose tone just reaches that limit is Rmax.

What “no peak” means

No peak means the radar cannot detect that target with the current chirp settings. The car is still there, but its tone is above the receiver bandwidth, so it is filtered out before the FFT ever sees it. It is not a fault: it is the limit of that chirp design.

Why a larger bandwidth B shortens Rmax

Sweeping more bandwidth in the same time makes the chirp steeper, so every target’s tone is higher and the 20 MHz limit is reached at a shorter distance. Same 60 m car:

This is the basic trade-off: large B gives fine detail (ΔR = c/2B, 3.75 cm at 4 GHz) but a steep chirp gives short reach. Real ADAS radars switch between modes:

Rmax in this demo is only the limit set by the receiver bandwidth. A real radar has a second limit: echo strength falls roughly as 1/R⁴, so a far or small target (a pedestrian instead of a truck) can be too weak to rise above the noise. That limit is not modelled here.
