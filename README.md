# MOSFET Carrier Flow

Interactive animation of how an NMOS / PMOS transistor works: carriers forming a channel and flowing, linked live to the drain-current equation and I–V curves.

- Toggle NMOS / PMOS
- 5 stages: Off → Depletion → Inversion → Linear (triode) → Saturation (pinch-off)
- VGS / VDS sliders, live current equation with substituted numbers
- Output (ID–VDS) and transfer (ID–VGS) plots

Open `index.html` in a browser, or visit the GitHub Pages site.
